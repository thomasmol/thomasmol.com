# Project

- SvelteKit, TypeScript, and Tailwind CSS
- Bun package manager and runtime
- Use Tailwind classes for all styling
- Keep the site simple
- Edit files directly
- Do not add tests unless requested
- Inspect package.json to understand project deps, stack and scripts

## Commands to run

- `bun format`: Format the code
- `bun lint`: Lint the code
- `bun check`: Run svelte-check

Occasionally, run these commands to ensure the code is formatted and free of errors. Don't run them after every small change.
